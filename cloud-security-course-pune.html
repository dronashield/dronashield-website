Course Overview

What This Cloud Security Course Covers

As organisations move critical workloads to AWS, Azure and Google Cloud, misconfigured cloud environments have become one of the most common causes of data breaches. DronaShield's Cloud Security course in Baner, Pune teaches students to secure cloud infrastructure the way enterprise security teams do, starting from the shared responsibility model and building up to identity, network, data and container security across major cloud platforms.

The course covers AWS identity and access management and native security services, Azure security fundamentals and Sentinel, an introduction to GCP security, container and Kubernetes security, and a dedicated module on cloud VAPT and misconfiguration assessment using tools like ScoutSuite and Prowler. Compliance frameworks relevant to cloud environments, including ISO 27001, SOC 2 and GDPR, are also covered.

Batches run in a hybrid format from our Baner campus, with students from Balewadi, Wakad, Hinjewadi, Aundh and Pashan attending evening or weekend sessions around existing jobs or studies. Every module includes hands-on practice on real cloud consoles inside controlled lab accounts, and the course closes with a capstone project securing a multi-cloud environment end-to-end.

Graduates leave with a DronaShield Institute completion certificate, practical experience across AWS, Azure and GCP security tooling, and a strong foundation for cloud security and DevSecOps roles. Our placement cell works with job-ready students on resume reviews, mock interviews and introductions to hiring partners across Pune's fast-growing cloud security industry.

Before You Start

Prerequisites

Cloud security builds on general IT and networking knowledge, so a little prior exposure helps, though it is not strictly mandatory.

  • Basic understanding of networking, operating systems and how applications are deployed.
  • Familiarity with any cloud platform is helpful but not required; the course starts from fundamentals.
  • A laptop capable of accessing cloud consoles and running lightweight virtual machines.
  • No formal certification is required to enroll in this Cloud Security course in Pune.

Curriculum

Complete Cloud Security Syllabus

Fourteen modules covering AWS, Azure and GCP security, identity, containers and compliance, each reinforced with a hands-on lab.

  • Module 01 — Introduction to Cloud Computing & Shared Responsibility Model
  • Module 02 — Cloud Security Fundamentals & Threat Landscape
  • Module 03 — AWS Identity & Access Management (IAM)
  • Module 04 — AWS Security Services (GuardDuty, Security Hub, CloudTrail)
  • Module 05 — Azure Security Fundamentals & Azure AD
  • Module 06 — Azure Security Center & Sentinel
  • Module 07 — GCP Security Fundamentals & IAM
  • Module 08 — Cloud Network Security & VPC/VNet Hardening
  • Module 09 — Container & Kubernetes Security
  • Module 10 — Cloud Storage & Data Security (S3, Blob)
  • Module 11 — Cloud VAPT & Misconfiguration Assessment
  • Module 12 — Cloud Compliance (ISO 27001, SOC 2, GDPR)
  • Module 13 — Incident Response in the Cloud
  • Module 14 — Capstone: Secure a Multi-Cloud Environment
